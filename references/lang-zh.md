# 中文语言层

中文的好处在短、在实、在动词。多数中文文病来自把英文句法搬进来：名词化、长定语、
被动、连接词堆叠。改的方向一致：拆、短、用动词、去虚字。

## 翻译腔：AI 中文最主要的来源
- 大模型的中文句法离人类英文比离人类中文还近（Llama-3.1）；"被 + 动词"出现 56 次，母语中文只有 10 次；
  合成数据越多的模型越严重（Guo 等，ACL 2025）[实测]。
- 英译中文档里 45% 有翻译腔，GPT-4 是 43%，来源是指令微调而不是预训练；让模型自己润色一遍能降到 25%（Li 等，ACL 2025）[实测]。
- 机翻和模型输出里"但是、然而、可是"这类转折连词是原创中文的两倍多，句子也更短（Kong 与 Macken 2025）[实测]。
- 中文语料里有区分度的译文句式：过长前置定语、"当……时"、"对于……来说"、句首"然而，"、"这意味着"复述（R 2.6–5.3）[实测]。
- 还有一类：用物理动作写心理（接住、击穿、收口、锋利），形容词加冒号开头（"逻辑很清晰："）[观察]。

| 句式 | 改前 | 改后 |
|---|---|---|
| 无需施事的"被" | 该模型被广泛应用于图像分类任务 | 该模型广泛用于图像分类 |
| 当……时 | 当训练损失不再下降时，我们停止了训练 | 训练损失不再下降，就停止训练 |
| 对于……来说 | 对于小样本场景来说，这种方法更为重要 | 这种方法在小样本场景下更重要 |
| 名词化轻动词 | 对数据进行了清洗并加以标准化 | 清洗并标准化数据 |
| "的"字堆叠 | 一种基于注意力机制的用于跨模态特征融合的方法 | 一种用注意力融合跨模态特征的方法 |
| 代词重复 | 作者提出了方法，作者认为它有效 | 作者提出一种方法，认为它有效 |
| 连接词过多 | 因为……所以……；但是……然而…… | 每个逻辑环节只留一个连接词 |
| 在……方面 / 的过程中 | 在模型训练的过程中，在精度方面有提升 | 训练中精度有所提升 |
| 直译搭配 | 展示了显著的改进；遭受夜盲症 | 精度提高 3.2 个百分点；患上夜盲症 |

分寸：良性欧化（"之一""与其说……不如说"、施事无关时的科技被动）在中文学术里是正常的。
标准是"母语作者会不会这样写"，所以作者本人的样稿比规则表更可靠（余光中"恶性西化与善性西化"之分）。

## 名词化与弱动词
"进行 / 作出 / 加以 / 予以 / 实现 + 抽象名词"把一个动词拆成两个词。还原成动词。
- 对数据进行了预处理 → 预处理了数据
- 作出了重要贡献 → 贡献很大（或直接说贡献了什么）
- 实现了精度的提升 → 精度提高了 2.1 个百分点
- 对该问题加以分析 → 分析这个问题

## "的"字
一句里超过三个"的"就该改。办法：把长定语拆成短句，或把修饰语挪到谓语后面。
- 基于注意力机制的多尺度特征融合的图像重建的方法 → 一种图像重建方法：用注意力机制融合多尺度特征
- 我们提出的方法的性能的优势 → 本文方法的优势在于……

## 被动与"被"
中文少用"被"，被动意义多靠语序或"受、遭、由"。科技文里"被"字句可以改成主动或无主句。
- 该参数被设置为 0.1 → 该参数设为 0.1
- 结果被证明是有效的 → 结果表明有效（证明一词另有分寸，见学术规范）

## 长定语与长句
定语超过 15 字，就拆。一句话里只放一个主要信息，次要信息另起一句。
句子长短要交替：连续三句都超过 40 字，读者会累；连续都是短句，会碎。

## 虚泛的词
"相关 / 有关 / 一定的 / 某种程度上 / 各种 / 一系列 / 多方面"不说清楚对象。
写出具体是哪条规定、哪些文件、哪几个方面；说不出对象，就删。
- 提交相关材料 → 提交身份证复印件和成绩单
- 存在一定的局限性 → 只在同分布数据上测过

## 关联词
中文靠意合，关联词能省就省。"因为……所以……""虽然……但是……"成对出现时，常常只留一个。
"首先……其次……最后"只在步骤确有先后时用。段落之间靠内容衔接，不靠"此外 / 与此同时 / 另一方面"。

## 四字格与对仗
四字格偶尔用是凝练，连用就是堆砌（"深入研究、全面分析、系统总结、广泛应用"）。
对仗工整的排比在公文里常见，在学术和技术写作里会显得空。

## 标点（GB/T 15834—2011；条款号来自转述，正式引用前核对原文）
- 破折号少用，不要拿它当万能连接；能用逗号、冒号或断句就不用。中文实测破折号是人类的 3 倍，但各模型差异很大。
  写法是占两个字宽的"——"，不用单个"—"或"--"，不在行末断开。
- 冒号只用在确有停顿、后面确实要展开的地方；不用"空转句 + 冒号"引出列表或结论（实测 9.4 倍）。
- 一段里不要连用多个分号；中文分号用于并列的长分句，不用于连接因果；列举项里已有句号的，项末不用分号。
- 引号：大陆标准是外层“”、内层‘’；「」是港台或个别风格指南的用法。引号用于引用和特指，不用于表示"所谓的"。
- 省略号写"……"（六个点、两个字宽），不和"等"连用（"菠菜……等"错，"菠菜等"对）。
- 感叹号只用于强烈感情，连用不超过三个；学术、技术、汇报文字里基本不用。
- 书名号只用于书、文章、文件等题名，不用于课程、项目、奖项、机构名；英文书名用斜体，不套《》。
- 顿号用于并列词语；相邻数字表概数不加顿号（六七十、八九公里）。一句里顿号堆到五六个，考虑改成表或拆句（实测 1.8 倍）。
- 括号里的话如果重要就放进正文，不重要就删。
- 不用 →、✅、• 这类符号代替文字；中文句子里用全角标点，全角标点两侧不加空格；不重复标点（"！！""？！？！"）。

## 中英混排
- 中文与英文、数字之间加空格（"在 LeanCloud 上"）；数字与单位之间加空格（"10 Gbps"），但"90°""15%"不加（中文文案排版指北）。
- GB/T 15834 对中英间空格没有规定；投稿、专利、公文按版式要求，一般文档按排版指北。一份文档内只选一种。
- 中文句子里夹的完整英文句子保留半角标点。
- 交付前检查全半角混用：中文句子里的半角逗号、括号、冒号，英文、代码里的全角标点。

## 术语与指代
同一事物全文一个名字，不为避免重复而换说法。术语第一次出现给出全称和英文，之后固定用一个。
"其、该、此"指代不清时，重复名词比指代模糊好。

## 节奏
朗读一遍。读着拗口的地方，就是读者卡住的地方。好的中文读起来有起伏：长句铺开，短句收住。
