# 文体：汇报（PPT 文字、周报、组会、给导师的进展）

读者时间少，要在几秒内知道结论和需要他做什么。汇报写的是判断和证据，不是工作日志。
AI 汇报的问题主要不在排版，而在四处：话题词标题没有主张、每页同一个节奏、该放数字的地方放了套话、
仪式化的开场和结尾。这几处按下面改，大部分 AI 味会一起消失。

## PPT

### 标题和正文
- 每页一个结论，标题就是这句结论（"频域分支使跨相机 Rank-1 提高 4.1 个点"），不是话题词（"实验结果"）。
  只读所有标题，应当能读出整个论证（Minto 的"幽灵稿"检验）[规范]。
- 正文只放支撑这句结论的证据：一张图或一张表，加不超过三行说明（Alley 的断言—证据结构）[规范]。
- 三秒检验：看三秒能说出这页要说什么（Duarte）[规范]。
- 数字一律带对比对象和条件（相对哪个基线、哪个数据集、哪个指标、几个 seed）。
- 对比用表，表里加一列"判断"（提升 / 持平 / 下降 / 待定）；图上直接标出要看的那个差值。

### AI 做的 PPT 一眼能认出的地方
| 形态 | 依据 |
|---|---|
| 话题词标题：背景、意义、总结、Overview、Key Insights、Challenges | [规范] 断言式标题正是为纠正它 |
| 每页都是标题加四条长度相同的要点 | [观察] 厂商样本 62%（数据宽松看待） |
| 三个等大卡片配图标，要点"什么也没说" | [观察] 设计师评论 |
| 标题下的装饰横线、页眉色条、侧边色条 | [规范] Anthropic pptx 技能：标题下加横线是"AI 生成幻灯片的标志" |
| 每页同一种版式 | [规范] 同上："不要重复同一种版式" |
| 配色放到任何别的主题上也一样成立 | [规范] 同上 |
| 标题大小写不一致、斜体衬线收尾花字、全大写眉题 | [观察] |
| 以"谢谢""Q&A""Questions?"结束 | [观察] 厂商样本"Thank You"收尾 58%、"Questions?" 31% |
| 页数注水：25 页能说完的事 12 页就够 | [观察] |
| 讲稿只是把页面念一遍 | [观察] 厂商样本 54% |

检验：把装饰删掉，页面一样清楚，那装饰就是多余的 [观察]。

### 改法
- 版式随内容变：对比页、大数字页、图表页、引语页各不相同；页数由内容决定。
- 议程页如果只是复述各节标题，删掉；需要的话第二页写一句故事线（答案本身）。
- 最后一页写请求和决定，不写"谢谢"：
  "需要导师决定：(a) 是否追加 MSMT17；(b) 是否改用 ViT 骨干。我倾向 (a)，约 2 天 GPU。"
- 页面放"是什么"，讲稿说"为什么"；细节放讲义或附录，不做成满页文字的"幻灯文档"（Reynolds）。
- 用户给了模板时按模板走，只在模板内部写实；成品交 `report2ppt` / `nature-paper2ppt`。

改前 → 改后（组会，数字示意）：
- 背景 / 意义 → "现有 ReID 方法跨相机时 Rank-1 从 91.2% 降到 63.5%"
- 实验结果 → "加入频域分支后 Rank-1 +4.1（63.5→67.6），mAP +3.8，只增加 0.6M 参数"
- 存在问题 → "遮挡子集上增益消失（+0.2），疑似频域特征被遮挡区域污染，下周做 mask 对照"

## 周报与进展汇报

结构（各部分长度随内容）：
1. 结论：第一句就是结果或需要对方做的决定，带数字。
2. 证据：只写支撑结论所必需的；每个数字带基线和条件（数据集、划分、seed、版本）。
3. 问题：坏结果和好结果一样清楚地写，附下一步诊断；要对方拍板的给两个选项和推荐项
   （"让导师做选择题，不做问答题"）。
4. 下一步：对象 + 日期 + 完成标准；本周没做的事明说没做。

学术上的同类建议：UW 的 Ernst 要求每个目标可度量，"能否完成不存在歧义"；不要为等更好的结果拖延周报 [规范]。

### 典型 AI 周报
"本周主要开展了以下工作""一是……二是……三是……""取得了阶段性进展""有序推进""进一步优化""下一步将继续推进"
"存在的问题及解决措施"。共同的毛病：没有对象、没有数字、没有基线、没有日期、没有负责人 [观察]。
"基本、初步、较大提升、显著、持续"都是没有度量的论断。

- 改前："本周主要开展了以下工作：一是继续优化模型结构；二是进行了多组对比实验；三是撰写了部分论文内容。
  目前取得了阶段性进展，模型性能有所提升。下一步将继续推进实验。"
- 改后（数字示意）："频域分支把 val Rank-1 从 63.5% 提到 67.6%（同 seed、同划分，基线见台账 v12），
  但遮挡子集无增益（+0.2）。需要您定：是否追加 MSMT17 验证。下周：① mask 对照（周三）；② MSMT17 迁移（周五，待您确认）。
  论文 4 节初稿本周未动。"

### 述职与总结
"推动 X，使 Y 由 A 变为 B（口径、时间），我的贡献是 Z（不写团队笼统成果），遗留问题是 W。"
展现做成了什么，而不是做过什么。

## 要点卡
需要一页概览时：问题、做法、结果、下一步各一到两行，数字优先。
用户要求"显式的步骤一二三"时就按步骤写，不改成散文。

## 语气
对导师：直接、诚实；不用"取得了较好的效果"这类模糊说法。不用"在当今快速发展的时代背景下""赋能""抓手""深度洞察"。
公文和行政汇报里受众期待的规范用语按场合保留，但每项后面要有实事。
