# 写作档案

这是 prose 技能为你一个人积累的写作档案。prose 起草前会读取这里与当前文体、期刊、章节相符的内容，
改完后从你的修改和反馈里学习，补充到这里。所有文件都可以直接打开编辑。

- `rules.md`：已确认的偏好规则。只有出现两次以上、或者你明确要求过的，才会进入这里。
- `observations.md`：候选观察。单次修改里推断出的偏好先放这里，等再次出现或你确认后再升级。
- `glossary.md`：术语表，定下推荐写法和不用的写法。
- `venues/`：期刊卡片，写着投稿要求和从范文里学到的结构规律。
- `exemplars/<文体>/`：范文结构卡片，只记录结构和写法要点，不存全文。
- `samples/`：你自己满意的文字，起草时用作风格样本。只放你本人写的，文件名以文体开头，例如 `academic-en_intro_2026.md`。

管理命令见技能里的 `scripts/profile.py`，规则见 `references/learning.md`。
