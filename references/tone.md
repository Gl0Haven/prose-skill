# 开头、结尾、语气、比喻与量化

这五处是读者最先和最后碰到的地方，也是 AI 套路最集中的地方。改法的共同点：用作者手里的具体东西
（事实、数字、条件、判断）替换可以挪到任何文章里的句子。具体内容必须来自作者，改写者不编，缺了就标"[请作者补：……]"。

证据标记同 [deai.md](deai.md)。词表会随模型版本漂移（"delve"在 2025 年明显下降，"significant"还在涨）[实测]，
所以按句子的功能判断，不按词表判断。

## 1. 开头

| 形态 | 例子 | 依据 |
|---|---|---|
| 能放在任何主题前面的背景句 | "随着人工智能技术的快速发展，……日益重要"；"In today's fast-paced world" | [观察] 多个中英文清单 |
| 宣告式开场 | 值得注意的是、不得不说、有一说一、很多人不知道的是、真正的关键在于；Let's dive in、Here's the thing | [观察] |
| 形容词加冒号 | 逻辑很清晰：、问题很直接：、原因很简单：、结论很明确： | [实测] 冒号引出 3.8–9.4 倍 |
| 段首无指代的评论句 | "这一点很关键。"作段落第一句 | [实测] 4.4 倍，中文 11 项特征里最强 |
| 复述标题或问题 | 标题"## 性能"下第一句"速度很重要"；"You're asking about…" | [观察] |
| 自问自答式钩子 | "Why does this matter? Because…"；"Imagine a world where…" | [观察]；注意中文设问本身人类用得更多 |
| 先认可提问者 | "好问题！""Great question!" | [实测] 偏好数据奖励认同 |

改法：
1. 第一句换个主题也成立的，删掉。从结论、结果、对象或案例开始。
2. 第一句复述标题或问题的，删掉，让标题去承担标签。
3. 删宣告框架；框架里带了理由的，只留理由。
4. 背景定义式开头换成"造成问题的那个具体事实"。
5. 不要换上一个新的"惊人钩子"，那是同一种套路。

- 改前：随着人工智能技术的快速发展，图像篡改检测日益重要。
- 改后：扩散模型生成的局部篡改不留下压缩痕迹，基于 JPEG 双重压缩的检测器在这类图像上失效。
- 改前：值得注意的是，该方法在小样本下表现更优。 改后：该方法在小样本下表现更优。

文体例外：中文专利、开题、绪论按惯例从背景写起，保留一句短而具体的背景，不删光。论文引言可以从领域背景开始；随笔可以从场景开始。

## 2. 结尾

| 形态 | 例子 |
|---|---|
| 升华和展望 | 未来可期、让我们拭目以待、值得我们深思、具有深远的意义；the future looks bright、only time will tell |
| 挑战—乐观公式 | "尽管面临诸多挑战，……前景广阔"；Despite these challenges, X continues to thrive |
| 复述全文 | 由此可见、综上所述、不难看出，后面重说一遍已经说过的话 |
| 金句收尾 | 每段都以一句可以单独转发的短句结束；"Let that sink in." |
| 聊天收尾 | 希望对你有帮助、如需进一步……请告诉我；I hope this helps, let me know if… |

依据：均为 [观察]（Wikipedia、avoid-ai-writing、unslop、少数派作者"每个句子都要升华，读起来累"）。
没有找到结尾套路的人机对照统计；unslop 用"结尾重现开头词汇"做信号，小样本 12/12 命中、0/8 误报。

改法：
1. 停在最后一个具体的事实、结果、局限或下一步上。最后一段只复述前文的，删掉。
2. 预测要么写成可证伪的（带时间和数量，且有出处），要么删掉。
3. 删聊天收尾。
4. 全文最多一句警句；复述本段意思的警句删掉。
5. 升华换成具体的局限或尚未解决的问题。

- 改前：未来，随着技术不断进步，该方法必将迎来更广阔的发展空间。
- 改后：该方法目前只在 JPEG 压缩图像上验证过，PNG 无损场景未测试。
- 改前：这不仅是一次技术革新，更是一场思维方式的变革。 改后：删除，或并入上一句的具体结论。

文体例外：论文结论和总结小节必须总结并写局限，保留，但每句都要带结果；演讲、倡议、募捐信可以以行动号召结尾；
专利"有益效果"必须正面陈述，写成实验得到的具体效果。

## 3. 语气

| 形态 | 例子 | 依据 |
|---|---|---|
| 情绪认可、客服腔 | 我完全理解你的感受、先接住你的情绪；I hear you、It's understandable that | [实测] ELEPHANT：开放式建议中模型情绪认可 76%，人类 22%；间接措辞 87% 对 20% |
| 表演式坦白 | 说实话、我必须承认、说白了；Honestly?、I want to be upfront | [实测] "说白了" 3.2 倍；其余 [观察] |
| 刻意热情 | 很高兴地宣布、绝对值得；I'm thrilled to、absolutely | [观察] |
| 教程腔、拉近距离 | 让我们一起、我们来拆解一下；Let's break this down、Think of it as | [观察] |
| 两边都对 | 各有优劣、需要综合考虑；While X is true, Y is also important | [观察] |
| 体裁不分 | 让模型写小说或台词，仍是信息密集的学术腔 | [实测] Reinhart 等 PNAS 2025 |
| 用物理动作写心理 | 接住、击穿、收口、锋利的重构 | [观察] 翻译腔的一种 |

改法：
1. 开门见山给答案。除非是安慰、客服、道歉信，否则删掉对提问者和情绪的认可。
2. 删强调词和感叹号，写出那个让人兴奋的事实。
3. 坦白语气换成坦白的内容："说实话，样本不大" → "样本是 41 例"。
4. 先否后立改成直接肯定，除非被否定的说法确实有人主张过（"用 pnpm，不用 npm"这种真纠正保留）。
5. 表明立场：写出判断和依据；限定语只留给真正不确定的地方。
6. 内行之间的文字不用教程腔。
7. 不要机械禁用一种句式。有作者发现单禁"不是……而是"效果有限，因为每句仍在升华；要改的是升华的冲动。

- 改前：我完全理解你的感受，这不是你的错，而是系统设计的问题。
- 改后：这个报错来自配置在环境变量之前被读取，调整加载顺序即可。

文体例外：心理支持、客服、吊唁和道歉信需要承认情绪，只写一句具体的，不来回说；营销文案本来就要推销；
cover letter 需要适度积极；审稿回复和法律文本里的限定和否定一字不改。

## 4. 比喻与陈词

- 英文高频喻体和大词：tapestry、landscape、testament、beacon、cornerstone、game-changer、paradigm shift、
  watershed moment、double-edged sword、unlock、journey、ecosystem、catalyst [观察，Wikipedia 等]。
- 中文：灯塔、基石、桥梁、钥匙、引擎、双刃剑、催化剂、新篇章、浪潮、赛道、护城河、降维打击、拉通；
  彰显了、体现了、标志着……里程碑 [观察]。
- 拟人化主语：数据告诉我们、结果揭示了、the data tells a story、paints a clear picture [观察]。
- 中文实测：比喻总量人类反而多（比喻标记 2.4 倍）；偏 AI 的是把抽象事物拟人化的喻体，7.3 倍 [实测]。
  所以不要"删掉所有比喻"，只删可以挪到任何主题上的现成喻体和拟人化。
- 小说里的同类现象：四个模型的两万个故事里，近九成出现 Elara、灯塔、钟表匠一类的名字和设定 [实测，转引]。

改法：
1. 抽象名词换成实物："丰富多彩的文化图景"写出是哪三种文化；"……的基石"写出什么东西依赖它。
2. 换主题测试：喻体不改一字就能挪到别的主题上，就是现成货。
3. 删"彰显、体现、标志着、stands as a testament to"，除非有出处说明这件事确实重要。
4. 一段最多一个比喻，不混用喻体；用作者自己的具体意象。
5. 成语和诗词只在内容需要时用，不作结尾装饰。
6. 同一事物不轮换叫法，重复那个清楚的词。

- 改前：该技术如同一座灯塔，为行业发展注入强劲引擎，开启了崭新篇章。
- 改后：该技术把单张图像的检测时间从 3.2 秒降到 0.4 秒。（数字须由作者实测提供）

文体例外：科普、随笔、小说里原创而受控的比喻不是毛病；瓶颈、流水线这类已成术语的比喻照用；
政策文件和部分汇报场合，受众期待"抓手、赋能"这类公文词，按场合定。

## 5. 量化

| 形态 | 例子 | 依据 |
|---|---|---|
| 模糊数量词 | 诸多、大量、众多、一系列、各种；numerous、various、a wide range of、diverse array | [观察] |
| 无出处的权威 | 研究表明、专家认为、业内普遍认为；studies show、experts argue | [观察] |
| 编造的精确数字 | 没有出处的"提升 40%""市场规模 150 亿" | [实测] 引文编造率随模型和领域在 11%–57% 之间（另一基准 14%–95%） |
| 凑数框架 | "以下 7 个原因""五点建议" | [观察] |
| 用概括替代数据 | "显著提升""极大改善"代替具体数值 | [实测] 中文语料里人类的数字密度更高 |

改法：
1. 模糊数量词换成出处里的计数、范围或名称；出处里没有数，就只写已知的，或者问作者。
2. 绝不用数字填空。没有数字也找不到的，删掉论断或标"[请作者补出处]"。
3. "研究表明"写出作者、年份、样本量和效应，否则删。
4. 精确数字保持精确：结果部分的 38.4% 不改成"约 40%"；只有出处本身取整时才取整。
5. 删凑数框架，只留真正重要的几条。
6. "显著"只在做了统计检验时用；否则写差值和条件。

- 改前：大量研究表明，该方法在诸多场景下均取得显著提升。
- 改后：在 CASIA v2 和 Columbia 两个数据集上，F1 分别提高 3.1 和 2.4 个百分点（表 2）。（数据集和数值须由作者提供）

文体例外：引言和综述可以写"大量工作"，但要紧跟引文列表；科普和汇报可以说"约三分之一"；数字确实未知时，写"未知"是合法的。
