# 去 AI 味：诊断与改写

目标是把文字改好，而不是让它骗过检测器。两者经常冲突：检测器测的是可预测性，读者在意的是
信息、立场和准确。改好了，检测分数通常会顺带下降；只为降分而改，文字会变差。

证据标记：[实测] 有研究或语料统计；[观察] 社区与编辑经验，未量化；[推断] 合理但无直接证据。

## 1. AI 味是什么，从哪来

AI 味分两层，下层比上层更要紧。
- 表层：词汇、句式、格式上的高频模式（"至关重要""不是……而是……""**标签**：内容"）。
- 下层：写作本身的毛病，包括没有立场、迎合、虚假平衡、空泛论证、编造细节、过度对冲或过度自信、
  元叙述、复述问题、长文前后不一致。读者觉得"正确但空"，多半出在这一层。

成因：
- 指令微调和偏好训练造成文风偏移，而不是预训练。基础模型的用词和句法接近人类，指令微调后
  分词短语约为人类的 5 倍、名词化约 2 倍（Reinhart 等，PNAS 2025）[实测]。
- 奖励模型偏好更长、带列表和加粗的回答，偏好认同用户的回答，偏好语气自信的回答
  （Singhal 2023；Zhang 等 ACL 2025；ELEPHANT 2025：模型认同用户 72%，人类 22%）[实测]。
- 偏好"典型"的回答导致同质化：人类论述里 65.3% 的主论点是独有的，大模型只有 3.4%
  （Argument Collapse，2026）[实测]。所以 AI 文字常常每句都对，合起来什么也没说。
- 没有具体的作者和读者，只能写给"所有人"，于是面面俱到、不敢取舍 [推断]。
- 模型指纹主要在用词分布和内容选择上：打乱词序后仍能以 89% 的准确率认出是哪家模型，
  改写后 91%，只有压缩成摘要才降到 58%（Sun 等，ICML 2025）[实测]。所以只换词，等于把指纹挪了个地方。
- 中文还多一层翻译腔：句子用英文句法想好，再换成中文词（"我都接住""更锋利的重构"）[观察]。

## 2. 诊断：分七层看

先通读一遍，判断问题主要在哪一层，再动手。表层问题可以删和换，下层问题必须补内容或重写。

| 层 | 看什么 | 典型例子 |
|---|---|---|
| L1 词汇 | 高频套话、空泛形容、拔高词 | 至关重要、赋能、闭环、具有重要意义；delve、underscore、pivotal、showcase |
| L2 句式 | 先否后立、句末挂分词、系动词回避、凑三项、译文句式 | 不是……而是；, highlighting…；serves as；对于……来说、当……时 |
| L3 篇章 | 维度切片（从 A 层面……从 B 层面……）、对称收尾、复述式总结、预告式开头、段首无指代的评论句、序数词当小标题、套路开头和结尾 | "从技术层面看……从应用层面看……""本节将介绍……""这一点至关重要。"（段首）"未来可期" |
| L4 内容 | 无立场、虚假平衡、迎合、空泛论证、编造细节、对冲堆叠、过度自信 | "各有优劣"；"你说得完全正确"；"研究表明"（无出处）；"may potentially" |
| L5 格式 | 加粗泛滥、标签式列表、能写成段落的表格、emoji、标题过多、一句话小节、符号代替文字 | "**优势**：……" 连排五条；"## 背景"下只有一句 |
| L6 残留 | 聊天口吻、知识截止声明、工具标记 | "以下是""希望对你有帮助"；`oaicite`、`[cite: 1]`、`【85†L261】` |
| L7 长文 | 术语和数字前后不一致、论点漂移、同一骨架反复出现 | 第 2 节 84.0%，第 5 节 84.3%；每节都是"背景—方法—意义" |

怎么判断一段是不是空：把主题换成别的领域，这段话是否仍然成立？成立，就是空话 [观察]。

分层细则：标题、段落骨架和维度切片见 [structure.md](structure.md)；开头、结尾、语气、比喻、量化见 [tone.md](tone.md)；
翻译腔和标点见 [lang-zh.md](lang-zh.md) / [lang-en.md](lang-en.md)；PPT、周报、邮件、README、提交信息、论文题目摘要图题见对应文体文件；
起草时怎么预防、改完怎么评价见 [prevention.md](prevention.md)。

## 3. 改写：先守边界，再按层改

### 硬边界（优先于一切改写规则）
- 信息守恒：不增、不删、不改事实、数字、日期、公式、引用、术语；不改变主体、时间、条件、范围、
  否定和归因（"被认为与……有关"不能改成"导致"）。
- 不编造：缺具体内容时标"[请作者补：……]"，不替作者造数据、案例和经历。宁可留一点 AI 味，也不编一个事实。
- 文体保护：学术写作保留与证据挂钩的限定语、方法部分的被动、"we"、必要的路标句；专利保留法定用语；
  作者原有的习惯写法不按规则强改。
- 最小改动：改真正有问题的地方，不为显得用心而全文重写。没问题的句子原样保留。

### 按层改
- L1 词汇：先问这个词有没有信息。没有就删；有，就换成具体的东西（数字、名称、条件），不是换同义词。
- L2 句式：
  - 先否后立 → 直接说肯定的那一半。"这不是简单的精度提升，而是范式的转变" → "测试集精度提升 3.2 个点，训练成本不变。"
  - 句末挂分词（英文）→ 删掉，或换成它暗示的那个事实。
  - 系动词回避 → 用"是 / 有"、is / has。
  - 凑三项 → 实际有几项写几项。
  - 译文句式 → 拆开重排，让具体的人或物作主语。
- L3 篇章：维度切片改成按因果和主次组织（structure.md 第 3 节）；删对称收尾和复述式总结；删"本节将……"；
  重要的部分多写，次要的一句带过；段首评论句改为先给事实再评论，或直接删；开头从具体事实起，结尾停在结果或局限上（tone.md）。
- L4 内容（最费力，也最有效）：
  - 无立场 → 写出判断和它成立的条件："方法 B 快 4 倍、精度低 1.3 点；只有延迟是瓶颈时才用 B。"
  - 虚假平衡 → 证据偏向哪边就说哪边；"另一方面"只留给有证据的真反驳。
  - 迎合 → 删掉只表示认同或称赞的句子，直接给结论和理由。
  - 空泛论证 → 每段至少放进一样通用文章写不出来的东西：一个数字、一个具体案例、一个反例。
  - 编造细节 → 每个数字、人名、引用都要能查到出处；查不到就删，不要改写成更模糊的说法。
  - 对冲 → 一个论断最多一处限定，放在真正不确定的地方，并写明什么会改变结论。
  - 过度自信 → 动词强度与证据匹配（证明 / 表明 / 提示）。
- L5 格式：论证写成段落；列表只给真正并列、需要扫读的项；加粗只用于术语定义或少数关键数字。
- L6 残留：全部删除。
- L7 长文：先建一页事实表（术语、数字、主张），逐节对照；最后专门做一遍一致性检查。

## 4. 不是 AI 痕迹的东西（别误改）

中文语料实测（lieflat-less-ai-tone，283 万字，AI 与人类频率比）和英文研究显示，以下特征
不能区分 AI 和人类，按"去 AI 味"去改反而会把文字推离人类写法 [实测]：
- 句长和段长是否均匀（中文 R≈0.9–1.0）。节奏问题按可读性改，不当作 AI 痕迹。
- 被动语态（英文模型用无施事被动只有人类的一半）、中文"被"字句。
- 设问和反问：人类正文用得比模型多约 17 倍，不要删。
- 句内排比、真有先后顺序的"首先……其次……"。
- 中文的"进行 + 动词"名词化（R≈0.5，人类用得更多）。它仍然是文病（余光中），按文风改，不按 AI 痕迹改。
- 完美的语法、平淡的文风、学术腔本身（Wikipedia 编辑指南明确列为不可靠信号）。

中文里实测有区分度的：不是 A 而是 B（R 3.4）、破折号（R 3.0）、冒号引出提示或列表（R 3.8–9.4）、
序数词充当小标题（R 3.1）、段首无指代的评论句（R 4.4）、拟人化的理想化比喻（"智慧的导师"）、
译文句式（过长前置定语、"当……时"、"对于……来说"、句首"然而，"、"这意味着"，R 2.6–5.3）。
注意各模型差异很大：中文破折号每千字 Claude 4.25、DeepSeek 5.16、Gemini 0.51、GPT 0.11（lieflat）；
英文每千词 GPT-4.1 10.6、Claude Opus 4.6 9.1、DeepSeek V3 7.0、Gemini 2.5 Pro 3.5、GPT-5.4 1.4，人类散文 0.3–17（单作者预印本）。
新模型普遍在压破折号，只用逗号和句号的单调句子本身正在成为新特征。破折号按密度和本人基线判断，不一律删。

## 5. 矫枉过正（改完要专门查一遍）

去 AI 味规则用过头，会造出一种新的统一腔调，同样一眼能看出来 [观察，noslop / avoid-ai-writing]：
- 碎片化短句："就这样。没有然后。"
- 每段都以一句金句收尾。
- 硬加个人经历和坦白语气："说实话""我必须承认"。
- 人为制造利害："现在比任何时候都更重要"。
- 编造的具体细节（为了"具体"而造数字）。
- 所有段落换成同一种新骨架。
- 为了"不像 AI"故意写得口语、跳跃，破坏文体。
如果一批改写读起来彼此很像，就是用力过猛。

## 6. 各模型的典型毛病

| 模型 | 实测 | 观察 |
|---|---|---|
| GPT 系 | 分词短语、名词化偏多；开头"certainly / below is"；列表内加粗；GPT-4o 社交迎合最强（ELEPHANT） | "it's important to note"类防御性提示；知识边界免责；破折号 |
| Gemini | 斜体多、开头直接（Sun 2025）；迎合程度随任务而变；该拒答时倾向给错答 | 默认大量要点和标题；"从 A 层面……从 B 层面……"式维度切片和"几个方面"枚举（使用者经验，未见测量）；结论平滑掉数据里的不整齐 |
| Claude | 常回指提示（"according to the text"）、早期少格式（Sun 2025） | "You're absolutely right"；"load-bearing"、"not X, it's Y"、戏剧化短句；冒号分号代替因果连接；过度限定 |
| Llama | 道德问题"两边都对"比例最高（67–68%） | 冗长、emoji |
| DeepSeek | — | 排比、"不是……而是"、总分总加结尾升华、与场景不合的比喻 |
| Qwen / Kimi / 豆包 | Qwen 文本最难被检测 | 平顺但平淡；教辅腔；模板化 |

各模型的毛病随版本变化，词表会过时；按层诊断比背词表可靠。

## 7. 学术写作与 AIGC 检测

- 检测器测的是文本可预测性，不是质量，也不是作者身份。非母语作者的英文作文平均误报 61%；
  同一篇《荷塘月色》在不同中文平台上测出 62.88% 和 0%；同一篇纯 AI 论文在四个平台上最多相差 32 个百分点 [实测 / 媒体实测]。
- 知网、维普、万方只公开了笼统的检测维度，没有公开特征、阈值和误判率。
- 用大模型改写来"降 AI 率"不可靠，个例中改写后 AI 率从 62% 升到 94%；局部改标红段落可能让全文上升 [媒体实测，小样本]。
- 不做这些（只降分、伤文字，部分属于学术不端风险）：同义词替换表、故意加错字或异体字、来回机翻、
  注入低频词或噪声、随机打乱句长、改变归因（"研究表明"改"笔者认为"）。
- 合规而有效的做法：补入只有作者才有的一手内容（实验细节、数据、判断、局限）；保留写作过程记录
  （草稿、版本历史）以备申诉；按期刊和学校要求如实披露 AI 使用（披露声明交 `ars-disclosure`）。
- 用户明确要按某检测平台的维度处理时，说明上述局限后再做；`paper-spine-humanize` 按检测维度给分层约束，可配合使用。

## 8. 流程与交付

三种模式，开始前确定一种（用户没说时默认 B）：
- A 红笔报告：不改原文，逐条标出位置、所属层、问题、两三种改法；缺内容处标"[请作者补]"。适合作者自己的稿子。
- B 改写：按第 3 节改，交付改后全文、改动说明（按层归类）、待作者补充的清单。
- C 白名单：只改用户点名的问题类型，其余原样保留。

步骤：
1. 读懂：这段想说什么、给谁看、主张和数据是什么、哪些是作者的判断。
2. 诊断：按七层标问题，先处理 L4 内容层。
3. 改写：守硬边界，按层改。
4. 核对：逐句对照原文检查事实、数字、限定、归因是否守恒。
5. 查矫枉过正（第 5 节）。
6. 跑脚本 `scripts/check_prose.py --genre …` 查遗漏；命中只是提示，逐条判断。评价方法（盲评、信息守恒核对）见 prevention.md 第 2 节。
7. 朗读一遍。

不用"自评分数""字数减少了多少""AI 味消失了"代替第 4 步的核对。

## 9. 评价标准

每项 0–2 分。前两项是门槛，任何一项为 0 就不合格，不看总分。检测分数不纳入。
1. 意思守恒：没有新增或丢失事实、限定、引用。
2. 具体：论断带可核对的数字、名称、条件。
3. 立场：作者的判断和它的边界写清楚了。
4. 主次：最重要的结果比次要内容更醒目。
5. 信息流：旧信息在前、新信息在后，句尾落在要强调的内容上。
6. 动词：具体动词多，名词化堆叠少。
7. 简省：没有复述式总结和套话过渡。
8. 节奏：长短随意思变化。
9. 声音：与作者的原有写法一致。
10. 文体：保留了该文体的正当惯例。
